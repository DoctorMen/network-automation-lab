## Context

NOT-1 names page content and sub-second interface flaps, and a pending reboot past its window, as checks of their own. The routers run an image the lab must not change.

## Decision

node_exporter runs in each owned router's network namespace as a sidecar, listening on the loopback (net.ipv4.ip_nonlocal_bind lets it start before zebra sets the address), with only the collectors the checks need. Each router writes its pending-reboot state to a textfile with netlab/kernel.py. blackbox_exporter on noc requests h2's page and matches an entry only the real docroot has (decision 0018).

## Consequences

node_exporter reads /proc/net and /sys in the router's namespace; it has no access to FRR. The textfile is rewritten every 15 s, so a reboot's alert can lag that much more (expected_state.json alert_within). h2 runs no exporter: its QoS classes are a listed gap (monitoring/coverage.yml). The exporters answer plain HTTP on the loopback (RISK-32).
