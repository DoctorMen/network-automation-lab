## Context

OROS NOT-1 asks for a check per object, not per host, that pages while the host still answers ping, and for overdue reboots to alert. The lab had only CI tests, which run when CI runs.

## Decision

Prometheus scrapes the routers' exporters and the NOC's probes every 5 s and evaluates one generated rule per object; Alertmanager sends each alert, and its resolution, to a webhook sink on noc that the tests read back (decision 0018).

## Consequences

Two more images on the runner, and their RAM (docs/sizing/README.md). Every endpoint is plain HTTP inside noc's namespace or on a router's loopback (accepted as RISK-31 in docs/risks.yml). Prometheus' data lives in the container and is lost on a redeploy; that is fine for state checks and is the reason history goes to Loki instead (decision 0019). The sink is not a pager: nobody is woken up by it.
